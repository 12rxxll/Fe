提出用AI利用記録

レポート補助

採点者が、AIへ出した指示、AIが提案した内容、採用した実装、自分で確認して直した点を順番に追えるようにまとめています。

目的スマホ内蔵センサを使う暗記モードを追加 使用AIChatGPT / Codex 提出方法アプリ内記録とChatGPT共有チャットで説明
1. AIへ出した主な指示
  • 基本情報技術者試験の学習アプリであるFE Learning OSに、スマートフォン内蔵センサを使った暗記モードを追加するように指示した。
  • 既存の学習履歴、記述内容、復習状態、ChatGPT送信履歴、localStorageの保存形式を壊さないことを条件にした。
  • 端末を意図的に傾けた時だけ、現在見ている用語の「自分の記述」を一時的に表示し、元の姿勢に戻したら再び隠すように指示した。
  • iPhone Safariを優先し、DeviceOrientationEvent.requestPermission()が必要な場合に対応すること、センサ拒否時や非対応時にはボタン操作だけで使えるようにすることを指示した。
  • 外部通信、アクセス解析、外部CDN、外部API、カメラ、マイク、位置情報は使わず、センサ値を保存・送信しないように指定した。
  • 課題提出で説明しやすいように、センサ値の表示だけでなく、可視化、判定、操作として分かるUIを入れるように指示した。
2. AIが提案し、実装に採用した内容
  • スマートフォンの端末方向センサからbetaとgammaを取得し、暗記モード開始時または再調整時の姿勢を基準姿勢にする設計を採用した。
  • 現在のbeta/gammaと基準姿勢との差分から傾き量を計算し、25度以上で表示、10度以内で非表示に戻す判定を入れた。
  • しきい値を2つに分けるヒステリシスを使い、境界付近で答えの表示が点滅しないようにした。
  • 傾き量をそのまま使わず、複数回のセンサ値を平均して小さな揺れに反応しにくくした。
  • 暗記モード中は、用語名と問いは見えるままにし、利用者が自分で書いた記述欄だけを隠すオーバーレイ方式にした。
  • センサ状態、基準との差、現在の判定、表示開始しきい値までの残り角度を画面に出し、ゲージで可視化した。
  • センサが使えない端末でも課題の動作確認ができるように、長押しで答えを見る操作と、設定によってタップで切り替える操作を用意した。
3. AIの出力を自分で確認した方法
  • 実際にスマートフォンで暗記モードをONにし、自分の記述だけが隠れ、問いと用語名は表示されたままになることを確認した。
  • センサ操作ONで傾き量の表示が変わること、表示開始しきい値を超えた時だけ現在の用語の答えが表示されることを確認した。
  • 端末を元の姿勢へ戻した時に答えが再び隠れること、他の用語の記述まで同時に表示されないことを確認した。
  • センサを使わない状態でも、長押しボタンまたはタップ切替で答えを表示できることを確認した。
  • 設定を変更した後、暗記モード、センサ操作、しきい値、手動表示方式が実際のマップ画面へ反映されるか確認した。
  • localStorageの学習履歴や自分の記述が消えないこと、バックアップ対象からセンサの生値が除外されていることを確認した。
4. 自分で修正した点と理由
  • iPhone Safariではユーザー操作中でないとDeviceOrientationEvent.requestPermission()を呼べないため、センサ操作ONボタンを押した時に許可確認する流れへ修正した。
  • 暗記モードがOFFなのにセンサ操作だけONにできると動作が分かりにくいため、暗記モードOFF時はセンサ操作を無効化し、内部状態もOFFへ戻すようにした。
  • センサ許可を拒否した場合や非対応ブラウザの場合にアプリが止まらないよう、ボタン操作のみへ切り替える表示と処理を追加した。
  • 長押しで答えを見る時、iOSの文字選択やルーペが保存状態の文字に反応して邪魔になったため、保存状態の表示を選択不可にした。
  • 状態を色だけで表すと分かりにくいため、「センサON」「ボタン操作のみ」「答えを隠しています」などの文字ラベルも表示した。
  • PWAでは古いJavaScriptやCSSがキャッシュに残ることがあったため、変更のたびにバージョン番号とService Workerのキャッシュ名を更新した。
5. 課題要件との対応
  • 生成AIの使用: ChatGPT/Codexに要件整理、実装案、コード修正、確認観点の整理を依頼した。
  • スマートフォン内蔵センサ: DeviceOrientationEventで端末方向センサのbeta/gammaを利用した。
  • センサ値の表示: センサ状態、基準姿勢との差、表示までの残り角度を画面に表示した。
  • 可視化・判定・操作: 傾き量をゲージで可視化し、しきい値を超えた時だけ答えを表示する判定と操作に使った。
  • 安全性: センサ値を保存・送信せず、カメラ、マイク、位置情報、外部通信、アクセス解析を使わない設計にした。
  • 動作確認: iPhone SafariまたはPWAとして動作確認し、センサ許可やHTTPSが必要な点を問題点として記録した。
6. Codex共有リンクについて

Codexの codex://threads/... は、Codexアプリ内で自分の作業スレッドを開くための内部リンクです。通常のWeb公開URLではないため、採点者が外部ブラウザから閲覧できる共有リンクとしては使えません。また、この開発スレッドには課題以外の作業、GitHub操作、個人情報に近い内容も混ざるため、そのまま共有すると安全性と分かりやすさの両方に問題があります。そのため、課題提出では、この設定画面に整理したAI利用記録と、個人情報を含めない短いChatGPT共有チャットを提出用の証拠として使います。

この記録は採点用に説明を整理したものです。センサ値や個人情報は含めていません。
