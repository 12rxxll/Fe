## 1ページ目: 制作内容

### アプリ概要

制作したアプリは「FEL Tilt Memory Cards」です。基本情報技術者試験の用語カードを表示し、スマートフォンを基準姿勢から大きく傾けたときだけ答えを表示します。暗記学習中にすぐ答えが見えないようにし、意図的な端末操作で確認できるようにすることを目的にしました。

主な機能は、FE用語カード、端末方向センサの値表示、傾き量のゲージ可視化、しきい値判定による答え表示、長押しによる手動代替操作、自己確認ボタンです。

### 使用センサ

使用したセンサはスマートフォンの端末方向センサです。ブラウザの `DeviceOrientationEvent` を使い、前後方向の `beta` と左右方向の `gamma` を取得します。

アプリ開始時または「基準姿勢を登録」を押した時点の `beta` / `gamma` を基準にし、現在値との差から傾き量を計算します。傾き量が25度以上の状態を約0.5秒保つと現在のカードの答えを表示し、10度以内に戻ると再び隠します。小さな揺れで表示が点滅しないよう、移動平均と表示/非表示で異なるしきい値を使いました。

### 画面・動作

画面上部にはセンサ開始と基準姿勢登録のボタンを置き、その下に `beta`、`gamma`、基準との差、現在の判定を表示します。ゲージでは表示しきい値までの傾き量を可視化します。

中央には用語カードを表示します。通常は答えが覆い隠され、スマートフォンを傾けるか「長押しで見る」を押している間だけ答えが見えます。前後ボタンでカードを移動すると、次のカードは再び答えが隠れた状態から始まります。

### デザインポリシー

スマートフォンで片手操作しやすいよう、ボタンは44px以上のタップ領域を確保しました。配色は明るい背景、白いカード、緑系のアクセントで構成し、ダークモードにも対応しています。センサ状態は色だけに頼らず、「未開始」「センサON」「答え表示中」などの文字ラベルでも分かるようにしました。
