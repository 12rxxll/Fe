# 提出用ChatGPT共有チャット作成用プロンプト

以下を新しいChatGPTチャットに貼ってください。
ChatGPTの回答が出たら、そのチャットの共有リンクを作成し、レポートの「チャット記録」欄または提出フォームに貼ります。

注意:
- メールアドレス、パスワード、個人情報は書かない。
- この長いCodex作業スレッド全体は共有しない。
- 共有リンクは採点終了まで見られる状態にする。

```text
あなたは「センサと計測」の最終課題を確認する補助者です。
以下は、私が生成AIを使って制作したスマートフォンセンサWebアプリの制作記録です。
課題要件を満たしているか、レポートに書くべきポイントが不足していないか確認してください。

課題:
2026年度「センサと計測」最終レポート
B課題: スマートフォンセンサ Web アプリの制作

必須要件:
1. 生成AIを使用し、スマートフォン内蔵センサを1種類以上、アプリの機能に利用する。
2. センサ値の表示に加えて、可視化・判定・操作などの簡単な機能を1つ実装する。
3. index.htmlの1ファイルで完結させる。GitHub等での公開や動作動画の提出は不要。
4. 自分のスマートフォンで一度以上動作確認し、確認した環境と問題点をレポートに記載する。
5. 外部通信・アクセス解析を使わず、端末の情報を保存・送信しない。カメラ・マイク・位置情報は使用しない。

制作したアプリ:
基本情報技術者試験の学習アプリ「FE Learning OS」に、端末方向センサを使った暗記モードを追加した。
用語ごとに表示される問いは見せたまま、自分で書いた記述だけを隠す。
利用者は答えを思い出した後、端末を傾ける、または手動ボタンを使って答えを一時表示する。

使用したセンサ:
スマートフォンの端末方向センサ。
ブラウザのDeviceOrientationEventから beta（前後方向）と gamma（左右方向）を取得した。
暗記モード開始時または「センサ再調整」を押した時の姿勢を基準姿勢にし、現在のbeta/gammaとの差分から傾き量を計算した。

センサ値の表示・可視化・判定・操作:
- センサ状態を画面に表示した。
- 基準姿勢との差を角度として表示した。
- 傾き量をゲージで可視化した。
- 表示開始しきい値を約25度、非表示へ戻すしきい値を約10度にした。
- 25度以上の傾きを一定時間保った時、現在見ている用語の記述だけを表示するようにした。
- 元の姿勢に戻ると再び隠すようにした。
- センサが使えない場合や許可されない場合でも、長押しまたはタップ切替の手動ボタンで表示できるようにした。

iPhone Safari対応:
iPhone SafariではDeviceOrientationEvent.requestPermission()をユーザー操作中に呼ぶ必要があるため、「センサ操作ON」ボタンを押した時に許可確認するようにした。
暗記モードがOFFの時はセンサ操作を選べないようにした。
センサを拒否した場合や非対応の場合は、クラッシュさせずにボタン操作のみへ戻すようにした。

安全性:
センサ値は画面表示と判定にだけ使い、localStorage、サーバ、外部サービスへ保存・送信しない。
beta/gammaの生データ、基準姿勢、傾き履歴は保存しない。
外部API、外部CDN、アクセス解析、カメラ、マイク、位置情報は使用しない。

動作確認:
自分のiPhoneでSafariまたはホーム画面に追加したPWAとして確認した。
暗記モードONで記述が隠れること、手動ボタンで表示できること、センサ操作ONで傾き量が変化し、条件を満たした時だけ答えが表示されることを確認した。
問題点として、iPhoneではセンサ許可が必要なこと、HTTPSで開く必要があること、拒否時や非対応時はボタン操作へ切り替える必要があることが分かった。

生成AIへの主な指示:
既存のFE Learning OSを壊さず、スマートフォン内蔵センサを使った暗記モードを追加するように指示した。
端末を傾けた時だけ現在の用語の答えを表示すること、センサ値を保存・送信しないこと、カメラ・マイク・位置情報を使わないこと、iPhone Safariで使えるようにすることを条件にした。

AI出力に対して自分で確認・修正した点:
- DeviceOrientationEvent.requestPermission()をユーザー操作内で呼ぶように確認・修正した。
- 暗記モードOFF時はセンサ操作を選べないようにした。
- センサ拒否・非対応時にボタン操作のみへ戻すようにした。
- 状態を色だけでなく文字ラベルでも確認できるようにした。
- iOSの長押し選択が邪魔になる箇所を選択不可にした。
- PWAキャッシュで古い画面が残らないよう、バージョンとService Workerキャッシュ名を更新した。

上記の内容について、次の形式で確認してください。

1. 課題要件を満たしている点
2. レポートに必ず書いた方がよい点
3. 不足している可能性がある点
4. AI利用記録として自然な書き方
5. 200字程度の提出用まとめ文
```

必要なら、ChatGPTの回答後に続けて以下も送ってください。

```text
上の内容をもとに、レポート2ページ目の「AI利用記録」に貼れるように、表の各項目ごとに短く整理してください。
項目は「使用した生成AI」「モデル名」「チャット記録」「AIへの指示」「確認・修正」です。
```
