判定ルール

  • 基準姿勢との差が10度未満なら「安定」。
  • 10度以上20度未満なら「少し傾き」。
  • 20度以上なら「大きく傾き」。

センサ値は画面表示と判定にだけ使い、保存も送信もしません。

安全性

  • 外部通信、アクセス解析、外部CDNは使いません。
  • カメラ、マイク、位置情報は使いません。
  • ブラウザ内への永続保存は行いません。
